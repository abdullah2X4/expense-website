**إدارة أموالك بالذكاء الاصطناعي - الإصدار السادس**

تطبيق ويب متكامل لتتبع المصاريف مع مساعد ذكي VIP، ميزانية شهرية، ودعم متعدد العملات.

## ✨ المميزات الجديدة في V6

### 1. 💰 الميزانية الشهرية
- حدد ميزانيتك الشهرية وتابع استهلاكك بشريط تقدم تفاعلي
- تنبيهات تلقائية عند الاقتراب من الحد أو تجاوزه
- متاحة لكل الخطط

### 2. 🌍 دعم متعدد العملات
- التبديل بين الجنيه المصري `ج.م` والدولار الأمريكي `$`
- تحويل تلقائي للأسعار والمصاريف
- سعر صرف قابل للتحديث من لوحة الأدمن

### 3. 🗣️ دعم ثنائي اللغة
- عربي / English
- تبديل فوري بدون Reload
- حفظ تلقائي لتفضيلات اللغة

### 4. 🤖 المساعد الذكي VIP - خطة Max
- تحليل شامل لمصاريفك بالذكاء الاصطناعي
- توقع المصاريف الشهر الجاي
- خطة توفير مخصصة لك
- محادثة تفاعلية: اسأل أي سؤال عن فلوسك

### 5. 📊 رسوم بيانية متطورة
- Chart.js بألوان متدرجة
- توزيع المصاريف حسب التصنيف
- تحديث لحظي مع كل معاملة

### 6. 🔐 نظام خطط مرن
- **Free:** 50 معاملة + تصدير CSV
- **Pro - 25 جنيه/شهر:** معاملات غير محدودة + تصدير
- **Max - 50 جنيه/شهر:** كل المميزات + AI VIP
- **Max VIP - 550 جنيه/سنة:** وفر 50 جنيه
