# 💰 مصاريفي - Expense Tracker

### 📸 سكرين شوت من الموقع
![مصاريفي](screenshot.png)

## ✨ نبذة عن المشروع
موقع بسيط وأنيق لتتبع المصاريف اليومية، اتبنى باستخدام HTML, CSS, JavaScript. 
تقدر تضيف مصاريفك، تشوف الإجمالي، وتحذف أي حاجة مش عايزها. كل البيانات بتتحفظ في المتصفح.

## 🚀 المميزات
- **إضافة مصاريف**: ضيف اسم المصروف والمبلغ والتاريخ
- **حساب تلقائي**: بيحسبلك إجمالي المصاريف لوحده
- **حذف المصاريف**: امسح أي مصروف بضغطة واحدة  
- **حفظ تلقائي**: البيانات مش بتضيع حتى لو قفلت المتصفح
- **تصميم ريسبونسيف**: شغال على الموبايل والكمبيوتر زي الفل

## 🛠️ التقنيات المستخدمة
- **HTML5** - هيكل الموقع
- **CSS3** - التنسيقات والتصميم
- **JavaScript** - المنطق وحفظ البيانات بـ LocalStorage
